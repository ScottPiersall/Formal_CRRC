# Third-party materials

The experiments reference HumanEval, MBPP, EvalPlus, and pretrained models from their respective providers. Model identifiers and revisions are retained in protocol files so reviewers can identify the experimental inputs.

This package distributes numeric scores, task identifiers, aggregate execution outcomes, analysis code, and protocol settings. It excludes benchmark problem bodies, reference solutions, enhanced test bodies, tokenized benchmark prompts, model weights, and full generation traces. Numeric truth labels record saved execution outcomes; they do not enable an independent audit of the omitted executions.

The existing project release notes identify unresolved redistribution attribution for enhanced test data. Obtain those inputs from the upstream providers under their applicable terms before attempting a fresh end-to-end execution. A code license must not be assumed to license the associated test data. No upstream licensing determination has been made by this packaging step.
